# Notes:

#   * --index-strategy unsafe-best-match is REQUIRED: uv's default (first-index)

#     which librosa 0.10.0 imports lazily (removing it crashes the vocal splitter).
#   * The upstream 'futures' (py2-only) and 'spec_utils' (that's the local
#     lib/spec_utils.py, not a PyPI package) lines were intentionally dropped.
